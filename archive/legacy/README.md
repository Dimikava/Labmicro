# Legacy archive

This directory contains superseded controllers, launchers, diagnostics, tests,
and documentation from v1 through v6. It is retained for comparison and
rollback investigation only.

The supported runtime is the repository-root `start_zeiss_v7.bat` launcher,
the root compatibility wrappers, and the `zeiss_v7` package. Nothing under this
archive is imported by the supported v7 controller or included in normal test
discovery.
